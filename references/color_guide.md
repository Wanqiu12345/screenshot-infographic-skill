# 配色系统调研与设计依据 (Color Guide)

本 skill 的视觉色彩不是随机选的，而是基于成熟色彩理论，由 `scripts/color_system.py`
对「截图主品牌色」自动推导。目标：① 教程图风格跟随截图；② 不再单一寡淡；
③ 用色彩层次把用户视线引导到重点。

## 一、为什么"色彩单一"是问题

早期版本只有一个 `accent` 色，所有图标、编号、提示框都用它。结果是整张图"一片蓝/一片灰"，
眼睛没有落点，重点功能被淹没。专业教程图需要 **色彩层次 + 引导视线**。

## 二、三条理论支柱

### 1. 60-30-10 配色法则
设计界的经典比例，保证画面既有主调又不单调：
- **60% 中性色**（页面背景、卡片底、正文）—— 提供呼吸感，不抢戏
- **30% 主色**（截图品牌色，用于标题强调、徽章、主操作）—— 建立"这套图属于这个产品"的认知
- **10% 互补强调色**（`accent2`，主色在色轮 +180° 的互补色）—— 只用在"核心价值""重点提示"等极少数高潮位置，把视线一把拉过去

### 2. 色轮和谐（Color Harmony）
功能卡片需要"既区分又成系列"。采用 **类比色阶（Analogous）**：
以截图主色相为锚，在 **±60° 扇形内等距取 6 个色相**，并锁定相同的饱和度/明度。
这样 6 张卡片颜色像从同一支笔里流出，和谐耐看，又彼此可辨。
（若用完全随机的彩虹色，会像儿童贴纸，显得不专业。）

### 3. WCAG 对比度（无障碍）
卡片编号是"白字 + 彩色圆底"。彩色块必须足够深，白字才可读。
因此功能色固定到 `S≈0.62 / L≈0.55`（浅色主题），白字对比度满足 AA。

## 三、截图主色 → 教程图配色的映射（经验表）

| 截图主色相 | 调性 | 主色处理 | 互补强调色 | 适用观感 |
|---|---|---|---|---|
| 红 / 品红 | 暖 | 收敛饱和度避免刺眼 | 青绿 | 热情、促动 |
| 橙 / 黄 | 暖 | 提亮、降饱和 | 蓝紫 | 亲和、活力 |
| 绿 | 冷 | 略压明度显沉稳 | 品红 | 自然、成长 |
| 青 / 蓝 | 冷 | 保持（科技感天然适配） | 橙 | 专业、可信 |
| 紫 | 冷 | 略提亮 | 黄绿 | 高级、创意 |

> 主色本身来自 `extract_theme.py` 在截图中识别到的最鲜明品牌色；
> 若截图太素（无明显品牌色），回退到优雅的中性蓝 `#5A6CE0`（浅色）/ `#78AAFF`（深色）。

## 四、明暗自适应
- `avg_lum > 150` → 浅色主题：暖白底 `#FAF8F3`、白卡片、柔和。
- 否则 → 深色主题：深底 `#16181D`、深灰卡片、冷调强调；功能色更亮更饱和以在深底上跳脱。

## 五、接口
```
build_palette(accent_hex, theme, bg_hex=None) -> {
  theme, accent, mood, temperature,
  palette: {
    page_bg, card_bg, text_main, text_sub,
    accent, accent_soft, secondary, secondary_soft,
    accent2, accent2_soft, feature[6], feature_soft[6], line
  }
}
```
模板通过 `__ACCENT__ / __SECONDARY__ / __ACCENT2__` 等占位符取色；
概览图 6 张卡片各自取 `palette.feature[i]` 上色，细节图的"重点"区块取 `accent2`。
